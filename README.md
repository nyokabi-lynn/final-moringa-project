# Project Description

## 🌿 Kaizen Spa Website
The Kaizen Spa website is designed to provide services that aid in relaxation and improvement of overall wellbeing of an individual.We help stimulate a proper mind and body connection leaving you feeling whole again.
A  wellness website built with HTML, CSS and JavaScript. Designed with a natural greenery aesthetic to reflect the brand's commitment to organic, eco-friendly wellness treatments.

## 🌐 Pages

### Home — `index.html`
- Full screen hero section with background image
- Background overlay that lightens on hover revealing the image
- Hoverable title words that animate on hover
- Book Now button linking to booking page
- Features section showcasing our companies promises with emoji icons
- Footer with logo, quick links, services and contact info

### About — `about.html`
- Services grid built dynamically with JavaScript
- 6 service cards each with an image, description, price and Book Now button
- Clicking any card takes the user to the booking page
- Responsive — 3 columns on desktop, 2 on tablet, 1 on mobile

### Booking — `booking.html`
- Two column layout — info on the left, form on the right
- Form fields: first name, last name, email, phone, service dropdown, date, number of guests, special requests
- Date validation — user cannot select past dates or dates more than 1 year ahead
- Local storage — form data is saved automatically as the user types so nothing is lost on refresh
- Success message shown after form is submitted
- Local storage is cleared after successful submission

---

## ✨ Features

- Responsive layout using CSS media queries for desktop, tablet and mobile view
- Hamburger menu on mobile that animates into an X when open
- Background image on hero with hover overlay effect
- Services cards built dynamically from a JavaScript array
- Local storage saves booking form progress automatically
- Date input restricted to today and up to 1 year ahead
- Footer with permanent dark overlay
- Green spa aesthetic throughout using natural tones

## 🚀 How to Run

1. Clone or download the project folder
2. Open `index.html` in your browser directly, or
3. Use VS Code with the **Live Server** extension and click **Go Live**
4. The site runs on `localhost:5500`
